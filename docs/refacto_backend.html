Les 5 règles strictes

Chaque phase a été guidée par ces contraintes non négociables définies dans .cursorrules.

  • 1. 100 % anglais — Code, exceptions, logs, seeds, noms d'affichage des rôles preset.
  • 2. Zéro commentaire — Suppression de tous les ///, // et code commenté.
  • 3. Typage explicite — Interdiction absolue du mot-clé var.
  • 4. OOP / héritage — RepositoryBase, validateurs partagés, messages centralisés.
  • 5. Clean Architecture — Controllers minces, RBAC, scoping employé préservé.

Conventions préservées

Le refactoring n'a pas modifié les règles d'équipe ; il les a renforcées.

Backend C#

  • Typage explicite — aucun var
  • Paramètres préfixés p_, champs privés m_
  • Controllers minces — pas de try/catch
  • [Authorize] + [RequirePermission] sur chaque route
  • Soft delete + .AsNoTracking() pour les lectures
  • Exceptions remontées au ErrorHandlingMiddleware

Architecture 3 couches

  • Core — Aucune dépendance EF
  • Infrastructure — Implémentations EF, services métier
  • API — Points d'entrée HTTP uniquement
  • Interfaces dans Core, implémentations dans Infrastructure
  • DTOs Request/Response alignés front/back
